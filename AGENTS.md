# AGENTS.md

## Scope

These instructions apply only to software development agents performing
implementation, coding, debugging, refactoring, testing, or code-review tasks.

Development agents must use the TypeSafe/Jev skill when building or modifying
AI-powered features. They must read and follow the TypeSafe skill instructions
and consult the current TypeSafe documentation before implementing an
integration.

These instructions do not apply to non-development agents or tasks such as
general research, writing, design, project management, deployment,
administration, or documentation-only work.

Keep deterministic logic in regular code and keep TypeSafe API credentials
server-side.
